# 💱 Currency Converter Web App

A modern, responsive currency converter built using vanilla JavaScript and a real-time exchange rate API.

This project demonstrates API integration, asynchronous JavaScript, dynamic UI rendering, and a custom searchable dropdown component.

## ✨ Features

- 🔍 Custom searchable currency dropdown
- 🌍 Real-time exchange rate API integration
- ⚡ Instant conversion updates
- 🎨 Modern glassmorphism UI design
- 📱 Fully responsive layout
- 🔁 Currency swap functionality
- 🛡 Error handling for failed API requests
- 🧠 Clean modular JavaScript structure
- 🌐 Flag updates based on selected currency
